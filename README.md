# Jade Textile Factory System

Industrial command-center web app for Jade Textile garment factory operations.

Core principle: One Factory, One Database, One Operational Flow, One Management View.

Build order:
1. Supabase connection
2. Executive Command Center
3. Sewing Control Room
4. Order Master
5. Pre-Stock Readiness
6. Planning Board
7. Production Flow Tracker
8. Downtime and Manpower
9. Quality and Reports
10. Jade Textile Agent Panel

Codex rule: do not invent table names. Use the Supabase schema and migrations as the source of truth.
